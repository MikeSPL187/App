### 1.1. Цель

Сделать файловый менеджер, который закрывает те же задачи, что и прототип: локальные файлы, медиа, архивы, сеть, облака. При этом он должен:
- безопасно хранить пароли, ключи и токены и честно проверять TLS;
- быть удобным: современный Material 3, бесплатная тёмная тема, крупные зоны касания;
- быть быстрым и аккуратным, без навязчивой рекламы.

### 1.2. Что не входит в работу

- Код, ресурсы, значки и тексты прототипа **не используются**. Всё пишется и рисуется заново. Декомпилированный код в проект не попадает.
- Нет iOS, веб- и десктоп-версий.
- Нет собственного облачного хранилища и серверной части. Исключение — проверка покупок, если её потребует модель монетизации (раздел 10).

### 1.3. Термины

| Термин | Значение |
|---|---|
| Хранилище | Источник файлов: внутренняя память, SD-карта, USB, сервер SMB/SFTP/FTP/WebDAV, облако |
| Провайдер | Модуль кода, который реализует доступ к одному типу хранилища через общий интерфейс |
| Операция | Длительное действие над файлами: копирование, перемещение, удаление, сжатие, распаковка, загрузка |
| Корзина | Место, где удалённые файлы хранятся N дней с возможностью вернуть их |
| TOFU | «Доверие при первом использовании»: запоминаем ключ или сертификат сервера при первом подключении и предупреждаем, если он изменился |

## 2. Платформа и технологии

| Параметр | Требование |
|---|---|
| minSdk | 30 (Android 11). Обоснование: одна модель доступа «Все файлы» (`MANAGE_EXTERNAL_STORAGE`), без устаревших обходов для Android 10 и ниже |
| targetSdk / compileSdk | 36 (Android 16) с обновлением в течение 3 месяцев после выхода новой версии Android |
| Устройства | Телефоны, планшеты, складные. Android TV и ChromeOS — после v2.0 |
| Язык | Kotlin 100%. Java запрещена в новом коде |
| UI | Jetpack Compose, Material 3 (`material3` последней стабильной версии), Material You (`dynamicColorScheme`) |
| Асинхронность | Kotlin Coroutines и Flow. `AsyncTask`, `Thread` вручную и `Handler` для логики запрещены |
| Архитектура | MVVM/UDF: `ViewModel` + `StateFlow`, одна Activity, Navigation Compose |
| DI | Hilt |
| Данные | Room (индекс, история, закладки, корзина, очередь операций), DataStore (настройки) |
| Фоновая работа | WorkManager и foreground service типа `dataSync` для длинных операций |
| Медиа | Media3 ExoPlayer (видео и аудио), `MediaSessionService` для музыки, Coil (миниатюры) |
| Архивы | Apache Commons Compress (zip, 7z, tar, gz, bz2, xz), junrar (только распаковка rar). Лицензии проверить до релиза |
| Сеть | OkHttp; SSHJ или JSch (форк mwiede) для SFTP; smbj для SMB 2/3; Apache Commons Net для FTP/FTPS |
| Секреты | Android Keystore (AES-256-GCM) или Tink поверх Keystore |
| Аналитика и сбои | Firebase Crashlytics или аналог. Сбор только после согласия, без путей и имён файлов |
| Качество | ktlint/detekt, Android Lint без ошибок, R8 full mode, Baseline Profiles |

## 3. Пользователи и сценарии

| Пользователь | Типичные задачи |
|---|---|
| Обычный | Найти скачанный файл, освободить место, отправить фото, открыть документ или архив |
| Продвинутый | Работа с NAS по SMB, сервером по SFTP, правка конфигов, перенос между облаками, доступ к `Android/data` через Shizuku |
| Планшет и складной телефон | Работа в двух панелях, перетаскивание файлов |

Ключевые сценарии (проверяются при приёмке, раздел 12):
1. Найти недавно скачанный PDF и отправить его в мессенджер — не больше 3 касаний с главной.
2. Освободить место: открыть «Можно освободить», выбрать безопасные пункты, очистить, при необходимости вернуть из корзины.
3. Скопировать папку с фото на SD-карту, решить конфликты имён, не прерывая операцию.
4. Подключить NAS по SMB и скопировать файл с телефона.
5. Посмотреть видео из сетевой папки, поставить на паузу, позже продолжить с того же места.
6. Исправить строку в `config.yaml` и сохранить.

## 5. Функциональные требования

Обозначения: **[MVP]**, **[1.1]**, **[1.2]**, **[2.0]** — версия, в которой требование обязательно. Под каждым модулем даны критерии приёмки.

### F1. Навигация и оболочка [MVP]

- F1.1. Нижняя панель из 4 разделов: «Главная», «Обзор», «Сеть», «Инструменты». На ширине от 600 dp — навигационная рейка слева (макеты 01, 15).
- F1.2. Настройки открываются кнопкой в шапке главной.
- F1.3. Системная кнопка «Назад» и предиктивный жест «назад» работают на всех экранах.
- F1.4. Режим edge-to-edge, корректные отступы под системные панели и вырез экрана.
- F1.5. Несколько вкладок-окон («Открытые окна», счётчик в шапке) — **[1.1]**.

Приёмка: все разделы доступны из панели; «Назад» ведёт по истории внутри раздела, а затем на главную; поворот экрана не сбрасывает текущую папку и выделение.

### F2. Главная [MVP] (макет 01)

- F2.1. Строка поиска, открывающая экран поиска (F6).
- F2.2. Карточка внутренней памяти: занято и всего, процент, полоса с разбивкой по типам (фото, видео, приложения, аудио, документы, другое) и подписи с размерами.
- F2.3. Кнопка «Можно освободить N» показывает сумму безопасных пунктов из F13. До выхода F13 в v1.1 кнопка ведёт к большим файлам.
- F2.4. Сетка категорий: Фото, Видео, Аудио, Документы, Архивы, APK, Загрузки, Избранное.
- F2.5. Ряд «Недавние»: последние 20 файлов из MediaStore и индекса, кнопка «Все».
- F2.6. Если подключена SD-карта или USB, ниже карточки памяти появляется их карточка с той же разбивкой.

Приёмка: данные карточки памяти совпадают с системными настройками с точностью до 1%; разбивка строится не дольше 2 с после открытия (сначала показываются итоги, разбивка дорисовывается).

### F3. Обзор папок [MVP] (макет 02)

- F3.1. Шапка: имя папки, хранилище, число объектов и общий размер.
- F3.2. Путь в виде чипов, по любому чипу можно перейти к родительской папке.
- F3.3. Сортировка: по имени, дате, размеру, типу, по возрастанию и убыванию. Опция «Папки сверху». Настройка запоминается для каждой папки отдельно.
- F3.4. Вид «список» и «сетка», переключатель в панели над списком.
- F3.5. Строка списка: плитка с цветом категории (40 dp) или миниатюра, имя, «тип · размер · дата», метка «Новый» для файлов младше 24 часов, кнопка действий.
- F3.6. Кнопка «Создать»: папка, текстовый файл.
- F3.7. Меню действий файла: открыть, открыть с помощью, поделиться, копировать, переместить, переименовать, сжать, в избранное, на рабочий стол, свойства, удалить.
- F3.8. Скрытые файлы показываются только если это включено в настройках.
- F3.9. Потянуть вниз — обновить. Изменения на диске подхватываются автоматически (`FileObserver` или повторное сканирование при возвращении на экран).
- F3.10. Открытие файла: свой просмотрщик для фото, видео, аудио, текста и архивов (если включён в настройках), иначе системный выбор приложения.

Приёмка: папка из 1000 файлов открывается и прокручивается без рывков (не более 1% пропущенных кадров на эталонном устройстве, раздел 11); имена с эмодзи, кириллицей и пробелами отображаются и открываются корректно.

### F4. Режим выбора [MVP] (макет 03)

- F4.1. Долгое нажатие начинает выбор; касание плитки тоже выбирает (настраивается).
- F4.2. В шапке: «N выбрано», суммарный размер, «Все», закрыть.
- F4.3. Снизу плавающая панель: Копировать, Переместить, Поделиться, В архив, Удалить; остальное в «Ещё».
- F4.4. Выбор диапазона: долгое нажатие на второй элемент при уже выбранном первом.
- F4.5. Выбранная строка отличается не только цветом, но и отметкой в круге (доступность).

### F5. Операции с файлами [MVP] (макет 04)

- F5.1. Копирование, перемещение, удаление в корзину и навсегда, переименование, групповое переименование (шаблон, нумерация, замена) — групповое **[1.1]**.
- F5.2. Буфер «Копировать/Вырезать → Вставить» сохраняется при переходе между папками и хранилищами.
- F5.3. Все длинные операции идут в очереди в foreground service с уведомлением. Отображаются: прогресс, байты, скорость, оставшееся время.
- F5.4. Лист «Операции»: активные, в очереди, завершённые; пауза, отмена, удаление из очереди.
- F5.5. Конфликт имён решается прямо в листе: «Заменить», «Пропустить», «Оставить оба», флажок «Так же для остальных». Показываются размер и дата обоих файлов.
- F5.6. После удаления в корзину — уведомление «Вернуть» на 10 с.
- F5.7. Корзина: срок хранения 30 дней (настраивается 7/30/90/навсегда), восстановление на исходный путь, очистка.
- F5.8. Перемещение в пределах одного раздела — переименованием, без копирования данных.
- F5.9. Проверки до начала: свободное место, перенос папки в саму себя, недопустимые символы имени, файлы только для чтения.
- F5.10. Прерванная операция (перезагрузка, нехватка памяти) после перезапуска предлагает продолжить или откатить. Частично скопированный файл не остаётся под конечным именем: запись идёт во временный файл, переименование в конце.
- F5.11. Сжатие в zip; распаковка zip, 7z, tar, gz, bz2, xz, rar; просмотр архива как папки без распаковки; архивы с паролем (zip AES, 7z) — **[1.1]**.

Приёмка: копирование 2 ГБ из 500 файлов на SD-карту завершается без ошибок и с совпадением контрольных сумм; при выключении экрана операция продолжается.

### F6. Поиск [MVP] (макет 05)

- F6.1. Поиск по имени: подстрока без учёта регистра и «ё/е».
- F6.2. Область: «Везде», «Эта папка», «Облака» (последнее — с v2.0).
- F6.3. Фильтры-чипы: тип, дата (сегодня, неделя, месяц, свой период), размер (больше/меньше).
- F6.4. Группировка результатов по хранилищу, подсветка совпадения, путь моноширинным шрифтом.
- F6.5. История запросов (до 20), удаляемая.
- F6.6. Поиск по содержимому текстовых файлов, PDF и DOCX — **[1.1]**, через индекс FTS в Room с фоновой индексацией при зарядке.

Приёмка: первые результаты по внутренней памяти появляются не позже 1 с, все — не позже 5 с для 50 000 файлов.

### F7. Категории и медиа [MVP]

- F7.1. Списки категорий строятся по MediaStore с запасным сканированием файловой системы.
- F7.2. Фото и видео — сетка с группировкой по датам и фильтрами по источнику (Камера, Скриншоты, мессенджеры) (макет 06).
- F7.3. APK: версия, установлено ли приложение, кнопка «Установить».

### F8. Просмотр фото [1.1] (макеты 18, 19)

- F8.1. Перелистывание, масштаб жестом и двойным касанием, лента соседних фото.
- F8.2. Действия: поделиться, повернуть (без потери качества для JPEG, если возможно), установить как обои, слайд-шоу, удалить.
- F8.3. Сведения: размер, разрешение, дата, параметры камеры, папка с переходом.
- F8.4. Если в фото есть координаты, показывать предупреждение. Опция «Удалять геоданные и серийный номер камеры при отправке» включена по умолчанию: отправляется копия без этих полей, оригинал не меняется.
- F8.5. Форматы: JPEG, PNG, WebP, GIF (анимация), HEIC/HEIF, AVIF, BMP.

### F9. Видеоплеер [1.1] (макеты 20, 21)

- F9.1. Воспроизведение локальных и сетевых файлов (SMB, SFTP, WebDAV через локальный прокси с токеном, см. S8).
- F9.2. Пауза, ±10 с (кнопки и двойное касание), шкала с буферизацией, главы, если они есть в файле.
- F9.3. Жесты: яркость слева, громкость справа, перемотка горизонтальным движением.
- F9.4. Скорость 0,5–2×; субтитры встроенные, SRT/ASS рядом с файлом, загрузка вручную; выбор аудиодорожки; масштаб «Вписать/Заполнить/Растянуть»; блокировка экрана; картинка в картинке.
- F9.5. Автопродолжение с места остановки (позиция хранится для последних 200 файлов) с кнопкой «С начала» вместо диалога.
- F9.6. Следующий файл из той же папки.
- F9.7. Рекламы в плеере нет.

### F10. Просмотр и работа с архивами [MVP]

- F10.1. Открытие архива как папки, извлечение выбранного или всего, «Извлечь сюда» и «Извлечь в…».
- F10.2. Защита от Zip Slip: путь каждого элемента после нормализации обязан оставаться внутри папки назначения.
- F10.3. Защита от «zip-бомб»: предупреждение, если распакованный размер превышает свободное место или в 100 раз больше архива.

### F11. Музыкальный плеер [1.1] (макеты 22, 23)

- F11.1. Воспроизведение файлов и папок, очередь, перемешивание, повтор (все/один/выкл), таймер сна.
- F11.2. Работа в фоне через `MediaSessionService`: уведомление, экран блокировки, гарнитура, Bluetooth, Android Auto не требуется.
- F11.3. Мини-плеер над нижней навигацией, когда музыка играет.
- F11.4. Отображение формата и битности (FLAC 24 бит и т. п.), обложка из тегов или `cover.jpg` в папке.
- F11.5. Эквалайзер — системный (`AudioEffect`), если доступен.

### F12. Текстовый редактор [1.1] (макеты 24, 25)

- F12.1. Открытие файлов до 5 МБ для правки, больше — только чтение с постраничной загрузкой (до 200 МБ).
- F12.2. Отмена и повтор (не меньше 100 шагов), поиск и замена с учётом регистра и регулярными выражениями.
- F12.3. Подсветка синтаксиса: JSON, YAML, XML, INI/properties, Markdown, shell, лог-файлы.
- F12.4. Определение кодировки (UTF-8, UTF-16, Windows-1251, KOI8-R и др.) с подсказкой, если текст выглядит искажённым; ручной выбор; сохранение в выбранной кодировке.
- F12.5. Окончания строк LF/CRLF сохраняются как в исходном файле, можно сменить.
- F12.6. Номера строк, перенос, размер шрифта, панель символов.
- F12.7. Предупреждение о несохранённых изменениях при выходе; автосохранение черновика при закрытии приложения системой.

### F13. Очистка и анализ [1.1] (макет 07)

- F13.1. «Безопасно» (выбрано по умолчанию): дубликаты (оригинал остаётся), установленные APK, кэш приложений во внешнем хранилище, корзина старше срока.
- F13.2. «Проверьте вручную» (не выбрано по умолчанию): большие файлы (порог 100/500 МБ), старые загрузки.
- F13.3. Дубликаты: сначала совпадение размера, затем хэш первых и последних 64 КБ, затем полный SHA-256. Оригиналом считается файл в DCIM/Camera или более старый.
- F13.4. Для каждого пункта причина безопасности («оригиналы останутся», «восстановится сам»).
- F13.5. Всё удаляется через корзину, кроме кэша.
- F13.6. Анализ папок: дерево по размеру.

### F14. Настройки [MVP] (макет 10)

| Группа | Настройки |
|---|---|
| Оформление | Тема: светлая/тёмная/системная (по умолчанию системная); цвета из обоев; плотность списка |
| Файлы | Скрытые файлы; корзина и срок; встроенные просмотрщики; приложения по умолчанию по типам |
| Безопасность | Блокировка приложения (биометрия/PIN); защищённая папка [2.0]; Shizuku/root [2.0] |
| Конфиденциальность | Персонализированная реклама; отчёты о сбоях; удаление геоданных при отправке |
| О приложении | Версия, лицензии открытого ПО, политика конфиденциальности, связь с разработчиком |

Тёмная тема и Material You бесплатны и не зависят от Premium.

### F15. Интеграция с системой [MVP]

- F15.1. Выбор файлов для других приложений: `GET_CONTENT`, `OPEN_DOCUMENT`, `PICK`.
- F15.2. Приём файлов: `SEND`/`SEND_MULTIPLE` → «Сохранить в…».
- F15.3. Отправка файлов через собственный `FileProvider`, ограниченный нужными каталогами.
- F15.4. Ярлыки папок на рабочий стол через `ShortcutManager` (только своим приложением; подпись в extras).
- F15.5. Сервис для системного файлового менеджера (DocumentsProvider) для сетевых хранилищ — **[2.0]**.

### F16. Сеть [1.2] (макеты 08, 09)

- F16.1. Протоколы: SMB 2/3 (SMB1 только по явному включению с предупреждением), SFTP (пароль и ключи ED25519/RSA/ECDSA с парольной фразой), FTP/FTPS (явный и неявный), WebDAV(S).
- F16.2. Поиск устройств в локальной сети (mDNS/NetBIOS) при добавлении.
- F16.3. Форма подключения: протокол сегментами, адрес и порт, логин, способ входа, название, «Проверить и подключить» (макет 09).
- F16.4. Проверка ключа SFTP по схеме TOFU: показ отпечатка SHA-256 при первом подключении, блокировка и предупреждение при смене.
- F16.5. Проверка сертификата HTTPS/FTPS: сначала системная проверка; при ошибке — показ сертификата и закрепление его SPKI по согласию пользователя; при смене — блокировка (S3).
- F16.6. Статус подключения в списке: в сети, недоступен, сессия истекла, сертификат изменился.
- F16.7. Чтение больших файлов потоком без полной загрузки, докачка при обрыве.

### F17. «Доступ с ПК» [1.2] (макет 08)

- F17.1. FTP-сервер на устройстве, по умолчанию FTPS с самоподписанным сертификатом и случайным паролем.
- F17.2. Слушает только IP-адрес Wi-Fi или точки доступа по выбору; в мобильной сети не запускается.
- F17.3. Адрес и QR-код, список подключённых клиентов с кнопкой «Отключить», автоостановка через 30 мин без активности.
- F17.4. Анонимный доступ только по явному включению и только для чтения.

### F18. Облака [2.0]

- F18.1. Google Drive, Dropbox, OneDrive, Яндекс Диск, Box, pCloud; Nextcloud/ownCloud через WebDAV (F16).
- F18.2. Вход только через OAuth 2.0 Authorization Code + PKCE в Custom Tabs (без WebView и implicit flow).
- F18.3. Токены хранятся по S1, обновляются автоматически; при истечении — статус «Войдите снова», а не ошибка.
- F18.4. Квота хранилища в списке; поиск по облаку через API сервиса.
- F18.5. Синхронизация папки «телефон ↔ облако» (одно- и двусторонняя) — после v2.0, отдельным ТЗ.

### F19. Две панели и перетаскивание [2.0] (макет 15)

- F19.1. На ширине от 840 dp или по кнопке «Две панели» — два независимых списка.
- F19.2. Перетаскивание файлов между панелями, а также в другие приложения в режиме разделённого экрана (`DragAndDrop` с `ClipData`).
- F19.3. Подсказка «Отпустите, чтобы скопировать сюда»; с зажатым модификатором (на клавиатуре) — перемещение.
- F19.4. Горячие клавиши для клавиатуры и мыши: Ctrl+C/X/V, Del, F2, Ctrl+K (поиск).

### F20. Premium [2.0] (макет 11)

- F20.1. Подписка (месяц, год с пробным периодом 7 дней) и разовая покупка; восстановление покупок.
- F20.2. В Premium: без рекламы, защищённая папка, две панели и вкладки, синхронизация с облаком, поддержка напрямую.
- F20.3. Бесплатно всегда: тёмная тема, Material You, все протоколы и облака, root/Shizuku, просмотрщики.
- F20.4. Перед списанием после пробного периода — уведомление за 2 дня. Цены и условия видны до оплаты.

## 6. Требования к безопасности и приватности

| ID | Требование | Откуда (аудит) |
|---|---|---|
| S1 | Пароли, ключи и токены шифруются ключом AES-256-GCM из Android Keystore (не экспортируемым). Ключ никогда не выводится из данных подключения или констант. При ошибке шифрования секрет не сохраняется, пользователь видит ошибку | S1 |
| S2 | Секреты исключены из облачных резервных копий и переноса на новое устройство. В копию попадает только список подключений без секретов; после восстановления — запрос повторного входа | S2 |
| S3 | TLS: системная проверка цепочки и имени хоста. Исключение — только закреплённый пользователем сертификат конкретного сервера (SPKI SHA-256). Глобального «доверять всем» в коде нет | S3 |
| S4 | Network Security Config: только системные CA; cleartext запрещён по умолчанию. HTTP и пользовательские сертификаты — только для серверов, добавленных пользователем, через собственный `TrustManager` | S4 |
| S5 | OAuth: Authorization Code + PKCE, Custom Tabs, минимально нужные scope с объяснением на экране согласия | S5 |
| S6 | FTP-сервер по F17: пароль и FTPS по умолчанию, только локальный интерфейс, автоостановка | S6 |
| S7 | Экспортируются только компоненты, без которых не работают системные сценарии. У каждого экспортированного компонента — обоснование в коде и проверка входных данных. `FileProvider` раздаёт только нужные каталоги | S7 |
| S8 | Локальный HTTP-прокси для медиа слушает 127.0.0.1, требует случайный токен в URL и живёт, пока идёт воспроизведение | S8 |
| S9 | Отчёты о сбоях и аналитика не содержат путей, имён файлов, адресов серверов и логинов. Сбор только после согласия (UMP/собственный экран) | S9 |
| S10 | Root-команды строятся только с экранированными аргументами, вывод разбирается по `\0`-разделителям; Shizuku предпочтительнее root | P4 |
| S11 | Блокировка приложения через `BiometricPrompt` с запасным PIN/паролем устройства; содержимое скрывается в списке недавних приложений (`FLAG_SECURE` по выбору) | — |
| S12 | Защищённая папка [2.0]: файлы шифруются (Tink Streaming AEAD), ключ в Keystore с `setUserAuthenticationRequired`, папка исключена из резервных копий и медиасканера | — |

Перед каждым релизом: проверка MobSF (или аналогом), ревью экспортированных компонентов и Network Security Config, тест миграции секретов.

## 7. Разрешения

| Разрешение | Когда запрашивается | Если отказано |
|---|---|---|
| `MANAGE_EXTERNAL_STORAGE` | При первом запуске на экране-объяснении | Работа через SAF с выбранными папками и сообщение, что часть функций недоступна |

| `INTERNET`, `ACCESS_NETWORK_STATE`, `ACCESS_WIFI_STATE` | Без запроса | — |

Каждый запрос — на экране с объяснением, зачем это нужно, и кнопкой «Не сейчас».

### 9.2. Абстракция хранилища

```kotlin
interface StorageProvider {
    val id: StorageId
    suspend fun list(path: Path, options: ListOptions): Flow<List<FileEntry>>
    suspend fun stat(path: Path): FileEntry
    suspend fun openRead(path: Path, offset: Long = 0): InputStream
    suspend fun openWrite(path: Path, mode: WriteMode): OutputStream
    suspend fun mkdir(path: Path)
    suspend fun rename(from: Path, toName: String)
    suspend fun move(from: Path, to: Path): MoveResult   // NotSupported → копирование + удаление
    suspend fun delete(path: Path)
    suspend fun space(): StorageSpace?
    val capabilities: Set<Capability>                     // RANDOM_ACCESS, SERVER_SIDE_COPY, THUMBNAILS…
}
```

Все операции F5 работают через этот интерфейс, поэтому копирование «SMB → SD-карта» и «Облако → SFTP» не требует отдельного кода.
