# Тихие файлы 1.1 — что сделано

Версия 1.1 добавляет к [версии 1.0](v1.0.md) встроенные просмотрщики и плееры, очистку памяти и оставшиеся пункты ТЗ с отметкой **[1.1]**. Работа шла по [техническому заданию](../spec/TZ.md) и [макетам](../design/mockups) 18–25 и 07.

| | |
|---|---|
| Пакет | `io.quietfiles` (debug — `io.quietfiles.debug`), версия кода та же: номер версии меняется при выпуске |
| Android | 11–16 (minSdk 30, targetSdk 36) |
| Новые модули | `feature/viewer` (фото), `feature/player` (видео и музыка), `feature/cleaner` (очистка и анализ) |
| Новые библиотеки | Media3 1.9.1 (ExoPlayer, MediaSession, ui-compose), zip4j 2.11.5 (zip AES) |
| Размер release APK | ≈ 7,0 МБ (было 4,7 МБ; почти всё прибавил Media3) |
| Код | ≈ 21 700 строк Kotlin в приложении, ≈ 3 100 строк тестов, 267 тестов (в 1.0 — 109) |
| Новые разрешения | `FOREGROUND_SERVICE_MEDIA_PLAYBACK`, `WAKE_LOCK` (музыка в фоне). **Интернета по-прежнему нет** |
| База данных | `quietfiles.db` версии 3 (автомиграции 1 → 2 → 3, проверены тестом) и отдельная `content_index.db` для поиска по содержимому |

Сборка и проверка — как в 1.0:

```bash
echo "sdk.dir=$ANDROID_HOME" > local.properties
./gradlew --no-parallel test lintDebug :app:assembleRelease
```

Снимки всех сценариев — в `app/build/screenshots/` (их делает `AppSmokeTest`).

### Безопасность и приватность

- **Пароли архивов** не пишутся на диск: журнал операций хранит запрос без пароля, пароль сжатия затирается сразу после операции, неверный пароль распаковки забывается. После перезапуска пароль спрашивается снова.
- **Индекс содержимого** лежит в отдельной базе `content_index.db`, которая не входит в облачную копию и перенос на новое устройство (правила резервного копирования включают только `quietfiles.db` и настройки). Выключение настройки удаляет индекс целиком.
- **Сервис музыки** экспортирован, как требует `MediaSessionService`, но подключиться к сессии могут только само приложение и доверенные системные контроллеры (`onGetSession`).
- **Поделиться фото**: по умолчанию отправляется копия без координат и серийных номеров камеры; оригинал не меняется (F8.4).
- **Позиции воспроизведения** — только путь и время, в основной базе; хранятся последние 200 файлов.

## Отличия от ТЗ и макетов

- **F9.1 Сетевые файлы.** Протоколы появятся в 1.2 (F16), поэтому плеер пока играет только локальные файлы. Локальный прокси с токеном (S8) делается вместе с сетью.
- **F9.2 Главы.** ExoPlayer не отдаёт главы MP4 и MKV, поэтому отметок глав на шкале нет. Шкала умеет их рисовать — подключим, когда появится источник глав.
- **F9.4 ASS.** Субтитры ASS/SSA показываются текстом без собственных стилей и позиций — так их отображает Media3.
- **F9.4 PiP на Android 11.** На Android 12+ окно открывается само, когда пользователь уходит домой во время просмотра; на Android 11 — по системной подсказке `onUserLeaveHint`, а также кнопкой в шапке.
- **F11 Позиции музыки.** Место запоминается только для записей длиннее 10 минут (подкасты, аудиокниги): песни и так начинаются сначала.
- **F13.1 Кэш приложений.** С Android 11 папки `Android/data` других приложений закрыты даже при доступе ко всем файлам. Поэтому пункт «Кэш и миниатюры» очищает системные миниатюры в общих папках и кэш самого приложения, а затем предлагает системный диалог «Очистить кэш приложений» (`StorageManager.ACTION_CLEAR_APP_CACHE`), если он есть на устройстве. Размер чужого кэша заранее не показывается — его знает только система.
- **F13 «Ещё инструменты».** В макете — «Доступ с ПК» и «Приложения»; они относятся к 1.2 и 2.0. До их появления на этих местах «Недавние» и «Избранное».
- **F13 Когда ищется лишнее.** Поиск запускается один раз за запуск приложения при открытии главной или «Инструментов» и идёт в фоне; повторно — после очистки. Хэшируются только файлы от 256 КБ с совпадающим размером.
- **F5.11 Создание 7z и rar с паролем.** Создаётся только zip AES-256: библиотека 7z на Java не умеет шифровать, а создание rar запрещает лицензия unrar. RAR 5 по-прежнему не открывается (ограничение junrar).
- **F6.6 PDF и DOCX.** Для PDF используется собственный лёгкий разбор (объекты, ObjStm, FlateDecode, таблицы ToUnicode): тяжёлые библиотеки прибавили бы к APK несколько мегабайт. Сканы без текстового слоя и зашифрованные PDF не индексируются. Из офисных форматов — только DOCX (не DOC и не ODT). В индексе «ё» заменена на «е», поэтому в отрывках виден текст с «е».
- **F6.6 Индексация вручную.** Кнопка «Обновить сейчас» запускает проход без условия зарядки — пользователь сам его попросил; по расписанию — только на зарядке и при невысокой разрядке батареи (раздел 8).
- **F1.5 Окна.** Окно помнит своё место, но не историю переходов внутри: «Назад» в восстановленном окне ведёт вверх по папкам, как обычно.
- **F8.5 HEIC и AVIF** открываются системными декодерами: HEIC — на всех поддерживаемых версиях, AVIF — с Android 12.
- **Ввод пароля и параметры сжатия** — нижние листы, а не диалоги: так поле ввода не перекрывает клавиатура, а набор полей для сжатия с паролем помещается целиком.

## Что проверено и что нет

- Юнит-тесты на логику: подписи времени, скорости, кодеков и разрешений; политика продолжения; поиск субтитров рядом с видео; заголовки FLAC и WAV; позиции воспроизведения и миграции базы; таймер сна; поворот фото и сведения EXIF; дубликаты, выбор пунктов, размеры папок; групповое переименование и откат; архивы с паролем (zip AES туда и обратно, 7z со скрытыми и открытыми именами, неверные пароли); извлечение текста из PDF/DOCX/Windows-1251 и FTS-индекс; окна.
- `AppSmokeTest` проходит новые сценарии на настоящих файлах и сохраняет снимки: просмотр фото и сведения (14, 15), видеоплеер и настройки (30, 31), музыка, очередь, мини-плеер (32–34), «Можно освободить» и очистка дубликатов, анализ папок (40–43), групповое переименование (44), архив с паролем и сжатие с паролем (45–48), поиск по содержимому (49), окна (50, 51). Видео и музыка в тесте проигрываются через фейковые декодеры Media3 — на устройстве декодирует система.
- lint без ошибок и предупреждений, release-сборка с R8 проходит.
- **Не проверено на устройстве** (эмулятора в среде нет): реальное декодирование видео и звука, PiP, уведомление и экран блокировки музыки, Bluetooth-гарнитура, системный эквалайзер, жесты яркости и громкости, системный диалог очистки кэша, скорость индексации больших папок с PDF. Нужен прогон по разделу 12 ТЗ.
