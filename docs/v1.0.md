# Тихие файлы 1.0 — что сделано

Новое приложение написано с нуля по [техническому заданию](../spec/TZ.md) и [макетам](../design/mockups). Код старого File Manager+ не использовался.

| | |
|---|---|
| Пакет | `io.quietfiles` (debug — `io.quietfiles.debug`) |
| Android | 11–16 (minSdk 30, targetSdk 36) |
| Стек | Kotlin 2.2, Jetpack Compose + Material 3, Hilt, Room, DataStore, WorkManager, Coil 3, Navigation (типобезопасные маршруты) |
| Размер release APK | ≈ 4,7 МБ (R8, сжатие ресурсов, только ru и en) |
| Код | ≈ 10 300 строк Kotlin в приложении, ≈ 1 200 строк тестов, 109 тестов |
| Разрешения | `MANAGE_EXTERNAL_STORAGE`, `REQUEST_INSTALL_PACKAGES`, `POST_NOTIFICATIONS`, `FOREGROUND_SERVICE(_DATA_SYNC)`, `USE_BIOMETRIC`. **Интернета нет.** |

## Сборка

Нужны JDK 17+ и Android SDK (platform 36, build-tools 36).

```bash
echo "sdk.dir=$ANDROID_HOME" > local.properties
./gradlew assembleDebug            # app/build/outputs/apk/debug/app-debug.apk
./gradlew test lintDebug           # юнит-тесты, Robolectric-тесты экранов, lint
./gradlew assembleRelease          # R8; локально подписывается debug-ключом
```

Robolectric-тест `AppSmokeTest` запускает приложение целиком (Hilt, навигация, настоящие файлы) и сохраняет снимки экранов в `app/build/screenshots/`. CI — `.github/workflows/android.yml`: тесты, lint, обе сборки, APK и снимки как артефакты.

### Безопасность

| | |
|---|---|
| S1–S6, S8, S10 | Касаются сети, облаков и root — в 1.0 этого нет, у приложения нет даже разрешения на интернет |

## Отличия от макетов и ТЗ

- **Шрифт.** Используется системный Roboto, а не Roboto Flex: так APK меньше на ~1 МБ, а текст выглядит как во всей системе.
- **Нижняя навигация** из трёх вкладок до появления сети (см. F1.1).
- **Release-подпись.** Локально release подписывается debug-ключом, чтобы APK можно было поставить. Для Google Play нужен свой ключ в CI (секреты репозитория) и сборка AAB.

## Что проверено и что нет

- 109 тестов: логика имён, сортировки и MIME; копирование, перемещение, корзина, импорт, архивы (включая Zip Slip, отмену и временные файлы); выбор диапазона; группировка поиска и галереи; обход ФС; удаление геоданных на настоящем JPEG; подпись ярлыков; разбор «Поделиться».
- `AppSmokeTest` проходит по 14 экранам в светлой и тёмной теме на настоящих файлах.
- lint без ошибок и предупреждений.
- **Не проверено на устройстве**: эмулятора в среде сборки нет. Нужен прогон по разделу 12 ТЗ на реальных телефонах — особенно доступ ко всем файлам, SD-карты и USB, системный установщик APK, биометрия и производительность на папке из 1000+ файлов.
