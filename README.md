## Главное

- **Безопасность:** пароли и токены «шифруются» ключом из имени хоста или константы в коде и уходят в облачную резервную копию; после одного согласия с сертификатом WebDAV проверка TLS отключается целиком.
- **UX:** тёмная тема только за деньги, пять палитр разных эпох, размытые растровые значки, реклама в шести местах, включая App Open.
- **Код:** Java без Kotlin, 103 класса на форке AsyncTask, ListView/GridView, `largeHeap`.
- **Редизайн:** Material 3 Expressive, бирюзовый цвет бренда сохранён (`#006A64`), Roboto Flex, единые векторные значки, нижняя навигация, лист операций с решением конфликтов, безопасные подключения, две панели на планшетах, бесплатные тёмная тема и Material You.

Анализ статический (apktool 2.10.0, jadx 1.5.1). Декомпилированный код в репозиторий не добавлен.
