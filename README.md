# Тихие файлы

Новый файловый менеджер для Android, сделанный по итогам разбора «Файловый менеджер +» (`com.alphainventor.filemanager`, версия 3.8.4): аудит безопасности, кода и UX, список улучшений, макеты нового дизайна, техническое задание и **приложение версии 1.1**.

## Приложение

Kotlin, Jetpack Compose, Material 3; Android 11–16; без рекламы, аналитики и доступа в интернет.

- **1.0** — обзор, поиск, операции в очереди, корзина, архивы, категории и галерея, интеграция с системой: [`docs/v1.0.md`](docs/v1.0.md).
- **1.1** — просмотр фото, видеоплеер и музыка на Media3, текстовый редактор, очистка и анализ папок, групповое переименование, архивы с паролем, поиск по содержимому, окна-вкладки: [`docs/v1.1.md`](docs/v1.1.md).

```bash
echo "sdk.dir=$ANDROID_HOME" > local.properties
./gradlew --no-parallel test lintDebug :app:assembleRelease
```

Снимки экранов из дымового теста — в `app/build/screenshots/`; в CI они выкладываются артефактом.

## Главное

- **Безопасность:** пароли и токены «шифруются» ключом из имени хоста или константы в коде и уходят в облачную резервную копию; после одного согласия с сертификатом WebDAV проверка TLS отключается целиком.
- **UX:** тёмная тема только за деньги, пять палитр разных эпох, размытые растровые значки, реклама в шести местах, включая App Open.
- **Код:** Java без Kotlin, 103 класса на форке AsyncTask, ListView/GridView, `largeHeap`.
- **Редизайн:** Material 3 Expressive, бирюзовый цвет бренда сохранён (`#006A64`), Roboto Flex, единые векторные значки, нижняя навигация, лист операций с решением конфликтов, безопасные подключения, две панели на планшетах, бесплатные тёмная тема и Material You.

Анализ статический (apktool 2.10.0, jadx 1.5.1). Декомпилированный код в репозиторий не добавлен.
